# Мини-игра [Adventure]

## Особенности реализации:

- Управление ресурсами приложения реализовано с помощью пакета **Addressables**.
- Процесс внедрения зависимостей реализован с помощью Zenject.
- Взаимодействие классов и систем реализовано с помощью реактивного программирования (библиотека R3). 
- Анимации реализованы c помощью DoTween.
- Асинхронные операции реализованы c помощью UniTask.

## Основные системы:

- **AssetManager** - реализует методы загрузки/выгрузки игровых ресуров из локальных и удалённых AssetBundle. Проведена оптимизация работы в виде создания пула загруженных объектов.
- **SceneLoaderWithProgress** - сервис для загрузки сцен с отображеием прогресса. 
- **GameCycle** - реализовывает события старта, паузы, возобновления и завершения игры.
Классы соответствующим образом реагируют на игровые события.
- **LevelZoneSystem** - система динамического изменения уровня. Игрок осуществляет переход между различными локациями путём преодоления *TransitionToZone*. Пересекая *TransitionTrigger*, игрок активирует подгрузку соответствующей локации.
- **PlayerCharacter** - игровой персонаж, который перемещается по локациям. Для его реализации применён *Component Design*. 
- **PlayerCharacterSkinSystem** - система, позволяющая настраивать и отображать различные облики персонажа. Взаимодействие с UI-элементами системы построена на основе паттерна MVVM.
- **UISystem** - комплексное решение для отображения пользовательского интерфейса. Включает в себя *UIManager* - менеджер UI-элементов, *ScreenFactory* - фабрику пользовательских окон, *ScreenSwitcher* - диспетчер окон.
