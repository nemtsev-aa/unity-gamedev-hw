# Информация о игровых сессиях и сундуки с наградой

## Игровые механики:

- Посчёт времени игровой сессии на основе информации о дате входа и выхода.
- Вывод истории сессий и информации о текущей сесии в интерфейс.
- Получение различных наград из сундуков, которые можно открывать через определённый интервал времени.

## Особенности реализации:

- Управление игровым процессом осуществляется с помощью пользовательского интерфейса.
- Процесс внедрения зависимостей реализован с помощью Zenject.
- Взаимодействие классов и систем реализовано с помощью реактивного программирования (библиотека R3). 
- Анимации UI-компанентов реализованы c помощью DoTween.
- Настройка систем и компанентов осуществляется с помощью OdinInspector.
- UI-элементы организованы с помощью паттерна MVVM.

## Основные системы:

- **GameCycle** - система управления состояниями игры. *GameStates* - enum-файл, содержащий все доступные состояния. *GameCycleView*-виджет с помощью которого пользователь может переключать состояния игры.    
- **SessionTracker** - система отслеживания данных об игровых сессиях. *SessionDataSaver* служит для загрузки/сохранения данных о сессиях в формате Json в PlayerPrefs. *JsonDateTimeConverter*, *JsonTimeSpanConverter* - конверторы, необходимые для сериализации/десериализации данных в Json-формат. *SessionData* - класс, используемый для сериализации/десериализации данных, *ReactiveSessionData* - класс, необходимый для отображения изменяющихся данных о дате/времени в UI.
*CurrentSessionInfoPopup* - окно для отображения информации о текущей сессии. *SessionHistoryPopup* - окно для отображения информации сессиях. *SessionDataView* - виджет, визуализирующий дату и время входа, дату и время выхода, продолжительность сессии.
- **ChestsSystem** - система сундуков с наградами. Настройка данной системы осуществляется через *ChestSystemConfig*-файл. *ChestData* - основные данные о сундуке. *ChestReward* - данные о награде. *ReactiveChest* - модель сундука, необходимая для взаимодейстия с различными ситемами. *ChestVisual* - визуальное представление сундука. *ChestsPopup* - окно отображающее текущее состояние сундуков. *ChestView* - виджет, визуализирующий информацию о типе, визуале и таймере сундука.
- **GameplaySystem** - связующая система, обеспечивающая общую работу вышеперечисленных систем.
