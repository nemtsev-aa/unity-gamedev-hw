# Инвентарь и экипировка персонажа

## Игровые механики:

- Добавление/Удаление/Просмотр содержимого инвентаря и описания предметов.
- Экипировка персонажа вещами, находящимися в инвентаре.

## Особенности реализации:

- Управление процессом экипирования осуществляется с помощью пользовательского интерфейса.
- Процесс внедрения зависимостей реализован с помощью Zenject.
- Взаимодействие классов и систем реализовано с помощью реактивного программирования (библиотека R3). 
- Анимации UI-компанентов реализованы c помощью DoTween.

## Основные системы:

- **InventorySystem** - система хранения предметов *InventoryItem*. Данные о предметах настраиваются с помощью *InventoryItemConfig*-файлов. Доступ к config-файлам предметов организован через *InventoryItemConfigProvider*, в котором все файлы распределены по категориям: экипировка, оружее, расходники, предметы для крафтинга. *InventoryEffectObserver* - класс, позволяющий применять эффекты от предметов, находящихся в инвентаре. *InventoryHelper* служит для удобного использования инвентаря другими системами, в том числе UnityInspector. *InventoryItem* реализован с использованием двух подходов Object-Oriented Design (*InventoryItemMetadata*) и Component-Oriented Design (*IItemComponent*). *InventoryItemFlags* - флаг-маркер, необходимый для разделения предметов по типам (группируемый, применяемый, экипируемый, содержащий эффект). *IItemComponent[]* - компоненты, предающие предмету особые свойства (например, *AgilityItemComponent* увеличивает значение Ловкости персонажа). Для защиты данных, содержащихся в *InventoryItemConfig*-файлах, работа с ними огранзована путём применения паттерна "Прототип". 
- **EquipmentSystem** - система экипировки персонажа. Количество и параметры слотов для экипировки задаются через *EquipmentServiceConfig*-файл. *EquipmentSlotPresenter* служит для отображения слотов. Доступная экипировка отображается с помощью *EquipmentPresenter*. Процесс экипирования реализован в виде Drag&Drop механики. *EquipmentEffectObserver* - позволяет изменять параметры персонажа при экипировании разными предметами.
- **CharacterModel** - слой данных персонажа, обладающего различными характеристиками *CharacterStat*. Стартовые значения харатеристик задаются с помощью *CharacterDefaultData*-файла. Другие системы могут получить доступ к характеристикам персонажа через *CharacterStatesProvider*. *CharacterStatView* служит для визуализации характеристики (паттерн MVVM).
- **CharacterInfo** - виджет для отображения характеристик персонажа. Реализован на основе паттерна MVVM.
- **GameplaySystem** - связующая система, обеспечивающая общую работу вышеперечисленных систем.
