# [Repository]

0) Исходные классы:
   - Unit - класс, хранящий основные данные о юните (тип, количество очков здоровья, позиция, поворот);
   - Resource - класс, хранящий основные данные о ресуре (тип, количество ресурса);  
   - UnitManager - менеджер юнитов, предоставляющий список юнитов на сцене и реализующий методы добавления и удаления юнитов;
   - ResourceService - сервис, предоставляющий список ресурсов на сцене.
1) Компаненты системы сохраения и загрузки (SaveLoadSystem):
   - ZenjectContext - контекст, позволяющий получить доступ к необходимым сервисам;
   - GameRepository - репозиторий, хранящий состояние сцены в виде Dictionary<string, string>;
   - SaveLoadManager - менеджер, реализующий методы сохранения и загрузки состояния сцены;
   - GameStateSaver's - классы, реализующие различные способы сохранения (BinaryToFile, JsonToFile, PlayerPrefs, JsonEncryptionToFile);
   - JsonConverters - классы, позволяющие конвертированть Unity-классы для дальнейшего сохранения (JsonVector3Converter, JsonVector3ArrayConverter);
   - EncryptionSystem - система шифрования.
2) Система фиксации данных о юнитах и ресурсах (Pattern_Memento):
   - Данные для изменения и хранения (UnitData, ResourceData);
   - Снимки текущего состояния юнита и ресурса (UnitMemento, ResourceMemento);
   - Универсальная история состояний, способная хранить как состояния юнитов, так и состояния ресурсов (MementoHistory);
   - Контроллер, управляющий добавлением и удалением состояний из истории (MementoHistoryController);
   - Классы синхранизирующие текущее состояние юнитов и ресуров на сцене с данными из снимка состояния (UnitMementoHandler, ResourceMementoHandler);
   - Фабрика параметров, необходимых для создания юнита на карте (UnitSpawnArgsFactory);
   - Окно, отображающее список состояний, находящихся в истории (MomemtosPopup);
3) Дополнительные системы и компаненты: 
   - Фасад для удобного доступа ко всем сервисам одного типа (MementoServices); 
   - Фабрика для создания фасадов (MementoServicesFactory);
   - Координатор, объединяющий и управляющий сервисами разных типов (MementoCoordinator); 
   - Общее окно для отображения историй снимков различных типов (CommonPopup);
   - Класс, позволяющий изменять количество юнитов на карте и наносить урон случайному юниту (UnitManagerPresenter);
   - Класс, позволяющий увеличивать и уменьшать количество ресурса в случайном источнике (ResourceServicePresenter);
