# Тестирование инвентаря и экипировка персонажа (NUnit Test Framework)

## Особенности реализации:
- **HW10Assembly** - Assembly Definition-файл, организующий взаимодействие отдельных систем (CharacterModel, EquipmentSystem, InventorySystem).
- **EqiupmentTests** - Assembly Definition-файл, на основе которого функционирует система тестирования.

## Основные элементы:
- **InventoryTests** - тесты инвентаря.
- **EquipmentServiceTests** - тесты сервиса экипировки.
- **EquipmentEffectObserverTests ** - тесты системы применения/отмены эффектов экипировки.
