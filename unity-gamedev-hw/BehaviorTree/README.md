# Бот-лесоруб [BehaviorTree]

## Игровая механика:

На сцене расположены: [Зона добычи ресурса], [Конвертер] и [Бот].
- [Зона добычи ресурса] содержит [Источники ресурса]. После взаимодействия [Бота] с [Источником ресурса], генерируется [Лут] и запускает режим его (Источника) восстановления.
- [Конвертер] - система, перерабатывающая один вид ресурса в другой (в текущей реализации, ветки в доски). 
- [Бот] - автономный механизм, взаимодействующий с [Зоной добычи] и [Конвертером].

По умолчанию, патрулирует окрестности [Конвертера] по точкам и анализирует [Зону добычи] на предмет наличия [Источников ресурса] и [Лута]. При их наличии, [Бот] завершает операцию *Патруль*, перемещается в [Зону Добычи], выбирает ближайшую цель. Если целью [Бота] является [Источник ресурса] - запускается операция *Добыча ресурса*, если [Лут] - операция *Сбора лута*. Собранный [Лут] помещается в *Инвентарь* [Бота]. В случае, если инвентарь заполнен, [Бот] совершает операцию *Доставка* (перемещает и загружает ресурсы в Конвертер). Цикл взаимодействия повторяется, пока в [Зоне добычи] есть [Источники ресурсов] или [Лут]. [Бот] возвращается к операции *Патрулирование*, если [Зона добычи] пуста и находится в режиме восстановления.

## Особенности реализации:

- Управление поведением Бота реализовано с помощью пакета **MonoBehaviourTree**.
- Процесс внедрения зависимостей реализован с помощью Zenject.
- Взаимодействие классов и систем реализовано с помощью реактивного программирования (библиотека R3). 
- Анимации реализованы c помощью DoTween.

## Основные системы:

- **FellingZone** - зона добычи ресурса, содержит *ResourceSpot*, из которых может быть получен *ResourceLoot*. *FellingZoneView* - виджет для отображения данных о зоне добычи. Зона добычи активируется в момент старта сцены.
- **Conveyor** - [Конвертер]. Разделён на инфраструктурные слои: *Core* (данные и бизнес-логика), *Visual* (анимации работы и зон занрузки), *UI* (отображение информации о состоянии и параметрах конвертера). Параметры системы настраиваются через *ConveyorConfig*. 
- **Player** - модель игрока. Разделён на инфраструктурные слои: *PlayerCore* - данные и компаненты (*MoveCompanent*, *CollectorCompanent*, *InventoryCompanent*). *Visual* (воспроизведение анимаций и отображение инструментов), *UI* - отображение информации о состоянии и параметрах. Параметры настраиваются через *PlayerConfig*. Для внедрения в **Blackboard** созданы классы *PlayerVariable* и *PlayerReference*. 
- **BotBrainData** - данные необходимые для автономной работы [Бота], включающие в себя *BotStates* - состояние, *Root* - родительский объект, *MoveTarget* - цель движения и другие. Параметры системы настраиваются через *BotBrainDataConfig*. Для внедрения в **Blackboard** созданы классы *BotBrainDataVariable* и *BotBrainDataReference*.
- **BorModel** - [Бот]. Включает в себя *BotBrainData*, *Player* и *UI*. Параметры системы настраиваются через *BotInstaller*. *BotInfoView* - отображает информации о параметрах Бота. *BotStateView* - отображает актуальное состояние Бота.
- **Nodes** - базовые структуры на основе которых реализовано дерево поведения Бота. Сбор и запись данных о игровом мире осуществляют ноды-сенсоры (*FarmingZoneSensor*, *InventorySensor*, *LootSensor*, *ResourceSpotSensor*), проверку определённых условий или состояний - ноды-условия (*DistanceCondition*, *HasFarmingZone*, *HasInventaryStatus*, *IsPatrol*), выполнение комплексных действий, содержащих несколько операций - компазитные ноды (*CollectLootSequence*, *DeliverySequence*, *FarmingOperationDecision*, *FarmingSequence*), конкретную реализацию операций - ноды-действия (*CollectionAction*, *DropLootAction*, *FarmingAction*, *LiftCargoAction*, *MoveAction*).
- **TimeScalerService** - сервис для изменения скорости игрового процесса. Реализован с помощью паттерна MVC. 
- **GameplaySystem** - связующая система, обеспечивающая общую работу вышеперечисленных систем. Система реализована на основе паттерна Mediator.
