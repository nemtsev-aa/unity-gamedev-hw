## Особенности реализации:

- **Архитектура ECS** - реализована на фреймворке *LeoEcsLite* с системой *Entity Manager*.
- **Dependency Injection** - процесс внедрения зависимостей реализован с помощью *Zenject*.
- **Реактивное программирование** - взаимодействие UI и игровых систем реализовано через библиотеку *R3*.
- **Паттерн MVVM** - используется для связывания UI с игровыми данными.
- **Object Pooling** - система пулинга для оптимизации создания юнитов.
- **Spatial Partitioning** - пространственное разделение для оптимизации поиска целей.

## Основные системы:

### 🎮 Игровой цикл (GameCycleSystem)

- **GameCycle** - центральный контроллер игрового состояния (*InitializingComponents*, *WaitingToStart*, *Playing*, *Pause*).
- **GameMediator** - посредник между UI и игровыми системами, управляет переходами между состояниями.
- **EntryPoint** - точка входа в приложение с DI-инъекцией.

### 👥 Управление юнитами (Unit Management)

- **UnitManager** - централизованное управление созданием, уничтожением и состоянием юнитов.
- **UnitFactory** - фабрика для создания юнитов через DI-контейнер.
- **UnitPool** - система пулинга для оптимизации переиспользования юнитов (*ArcherPool*, *SwordsManPool*).
- **UnitEntity** - базовая сущность юнита с конфигурируемыми параметрами.

### 🎯 Система таргетирования и боя

- **TargetingSystem** - интеллектуальный выбор целей с учетом приоритетов и расстояния.
- **SpatialTargetingGridSystem** - оптимизированный поиск целей через пространственное разделение.
- **SphereCastTargetingSystem** - физический поиск целей через SphereCast.
- **AttackSystem** - система атак (MeleeAttackSystem, RangeWeaponSystem).
- **ProjectileSystem** - управление снарядами (создание, движение, столкновения).
 
### ⚡ECS-системы движения и AI

- **NavMeshMovementSystem** - движение по навмешу с интеллектуальным перерасчетом пути.
- **RotateToTargetSystem** - поворот юнитов к целям.
- **CollisionAvoidanceSystem** - избегание столкновений между юнитами.
- **AnticipationSystem** - предсказание движения целей.

### ❤️ Система здоровья и урона

- **HealthSystem** - управление здоровьем юнитов и зданий
- **TakeDamageSystem** - обработка получения урона
- **DeathSystem** - уничтожение сущностей при достижении нулевого здоровья

### 🎭 Визуальные системы

- **AnimatorSystem** - синхронизация анимаций с игровыми состояниями (атака, движение, смерть).
- **TransformViewSynchronizerSystem** - синхронизация Transform с ECS-компонентами.
- **FXDamageSystem** - визуальные эффекты при получении урона.

### 🏗️ Система зданий

- **TownHallInstaller** - установка главного здания команды.
- **TownHallDestroyObserver** - отслеживание уничтожения баз для определения победителя.

### 🎮 Пользовательский интерфейс

- **UIManager** - центральный контроллер UI.
- **TeamPanel** - панель управления командой (создание юнитов, отображение здоровья).
- **GameCycleView** - управление игровыми состояниями (старт, пауза, завершение).
- **WinnerView** - отображение победившей команды.

### 🔧 Конфигурационные системы

- **UnitBaseConfigs** - базовые параметры юнитов (здоровье, скорость, радиус модели)
- **WeaponConfigs** - настройки оружия (MeleeWeaponConfig, RangeWeaponConfig)
- **UnitViewConfigs** - визуальные настройки для UI

## Ключевые особенности:

- **Модульная архитектура** - четкое разделение ответственности между системами
- **Оптимизация производительности** - пулинг объектов, пространственное разделение, батчинг ECS
- **Гибкая настройка** - конфигурируемые параметры через ScriptableObjects
- **Реактивный UI** - мгновенное обновление интерфейса через Observable
- **Интеллектуальный AI** - умный выбор целей, предсказание движения, избегание столкновений
- **Расширяемость** - легко добавлять новые типы юнитов, оружия и способностей
