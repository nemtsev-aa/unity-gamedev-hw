# Мини-игра [Resource Conveyor]

## Игровые механики:

- Покупка ресурсов в магазине для снабжения конвеера.
- Продажа готовой продукции для получения валюты.
- Покупка улучшений конвеера.

## Особенности реализации:

- Управление игровым процессом осуществляется с помощью интерфейса.
- Процесс внедрения зависимостей реализован с помощью Zenject.
- Взаимодействие классов и систем реализовано с помощью реактивного программирования (библиотека R3). 
- Анимации UI-компанентов реализованы c помощью DoTween.

## Основные системы:

- **Conveyor** - конвеер ресуров. Разделён на инфраструктурные слои: *Core* (данные и бизнес-логика), *Visual* (анимации работы и зон занрузки), *UI* (отображение информации о состоянии и параметрах конвеера). Параметры системы настраиваются через *ConveyorConfig*. 
- **ShopSystem** - система покупки/продажи ресурсов, включающая в себя хранилище информации о валютах. UI-элементы системы: высплывающие окна (*ShopPopupView*, *SellPopupView*), виджеты валют *CurrencyView*. Параметры системы настраиваются через *ShopSystemInstaller*. Система реализована на основе паттерна MVVM.
- **UpgradeSystem** - система улучшений конвеера. Реализованы и обобщены в виде каталога *UpgradeCatalog* следующие улучшения: «Время работы», «Объем зоны загрузки», «Объем зоны выгрузки». Улучшения создаются на основе Config-файлов. Для каждого улучшения определён максимальный уровень, таблицы стоимости и приращения характеристик для каждого уровня. UI-элемент системы - высплывающее окно ("Улучшения"). Параметры системы настраиваются через *UpgradeSystemInstaller*. Система реализована на основе паттерна MVVM.
- **GameplaySystem** - связующая система, обеспечивающая общую работу вышеперечисленных систем. Система реализована на основе паттерна Mediator.
